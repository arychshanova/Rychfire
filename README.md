# Rychfire v0.2.1

Исправление развёртывания от 31.10.2026: `numpy==2.2.6` заменён на `numpy==2.3.3`.
В присланном журнале Streamlit Cloud использует Python 3.14 и пытается собрать NumPy 2.2.6
из исходников. NumPy 2.3.3 официально поддерживает Python 3.11–3.14:
https://numpy.org/doc/stable/release/2.3.3-notes.html .
Конечной ошибки сборки в присланном фрагменте нет, поэтому эта несовместимость — вероятная
причина сбоя, а успешное развёртывание после исправления ещё требуется проверить в Cloud.
Сообщения о `use_container_width` и `st.components.v1.html` в журнале — предупреждения.

Если v0.2 уже загружена: достаточно заменить **только `requirements.txt`** в корне
GitHub файлом из нового архива, сохранить Commit changes и дождаться переустановки зависимостей.
При необходимости выберите Manage app → Reboot app. Удалять приложение и менять данные не нужно.

**Северный Казахстан — пользовательский AOI** · реальные обнаружения NASA FIRMS MODIS, 2006–2025.

## Состав и данные

- `app.py` — приложение Streamlit.
- `requirements.txt` — версии библиотек для установки; полный запуск с ними в среде сборки не проверен.
- `fire_archive_M-C61_833601.csv` — исходный файл, скопированный побайтно, 55 533 строки и 15 столбцов.
- `validation.json` — результаты проверок и ограничения проверки запуска.
- `verify.py` — повторяемая проверка данных и расчётов; не создаёт наблюдения.

SHA-256 исходного CSV: `447713ef898fc003def3acd489d71c443a874a181efdb5969d1c0dbf03e3039c`.
Период реальных обнаружений: **21.03.2006–21.11.2025**.
Инструмент: MODIS во всех строках; Aqua — 27 982, Terra — 27 551.
Координаты: 54.1114–57.1273° с. ш., 63.0371–68.2088° в. д.
Это экстент обнаружений, а не восстановленный полигон AOI.
В `version` записаны 6.03 и 61.03; значения не менялись.

Используются все строки: без пространственной фильтрации, обрезки административными границами,
удаления повторов, добавления или синтеза наблюдений. Полный охват всей Костанайской области
не заявляется. Точное название территории: **Северный Казахстан — пользовательский AOI**.

## Возможности

1. Календарь год × месяц и дневной календарь выбранного года.
2. Годовые суммы, средняя и медианная месячная сезонность за фиксированную базу 2007–2024.
3. Месячное отклонение: `(N / медиана для того же месяца в 2007–2024 − 1) × 100%`.
   База содержит каждый календарный месяц каждого базового года, включая нули строк.
   Медиана 0 даёт пустое значение, а не бесконечность или искусственный процент.
   Первый и последний неполные месяцы файла, периоды вне диапазона дат не получают отклонение.
   Это описательная статистика; пороги значимости, прогноз и индекс риска не рассчитываются.
4. Folium-карта: по умолчанию до 3 000 точек, настраиваемый предел 100–10 000.
   Выборка без возвращения с seed=42 берёт только реальные строки. Кластеры считают показанные точки.
   Карта не ограничивает расчёты и экспорт. OpenStreetMap и ресурсы Leaflet требуют интернета.
5. Экспорт исходного файла побайтно, выбранных строк с исходными полями, месячных и годовых сумм.
   Пользовательские экспорты имеют UTF-8 BOM; исходный файл не перекодируется.
6. Фильтры годов, confidence, Aqua/Terra и день/ночь. При открытии включены все 55 533 строки.
   Фильтры спутника, confidence и дня/ночи применяются также к базовой сезонности;
   фильтр лет задаёт отображение, но не меняет фиксированные базовые годы.
   Пустая выборка обрабатывается без создания фиктивных точек.

## Как читать календарь

0 — в файле нет строк за этот период. Это не доказательство отсутствия пожаров или наличия
полного спутникового покрытия. Пустые ячейки — несуществующие дни или периоды вне диапазона
первого/последнего обнаружения. Март 2006 и ноябрь 2025 — крайние частичные месяцы файла.
Первая и последняя даты обнаружений сами по себе не определяют начало и конец покрытия.

## Научные оговорки

- **Обнаружение не равно пожару.** Один пожар может давать много пикселей и повторные
  обнаружения разными пролётами. Некоторые тепловые аномалии имеют иные источники.
  Число строк не равно числу отдельных пожаров или площади выгорания.
- **2025 неполный.** В файле он заканчивается 21 ноября (406 строк).
  2006 начинается 21 марта. Полнота внутренних лет также не подтверждена:
  нельзя автоматически считать годы полными только по их наличию в CSV.
- **Только MODIS Terra/Aqua.** VIIRS не добавлен; сенсоры не объединяются.
- Облачность, дым, время пролёта, разрешение, пропуски и изменения спутниковых наблюдений
  влияют на число обнаружений. Межгодовые различия не доказывают климатический тренд.
- Confidence — показатель алгоритма, а не вероятность существования отдельного пожара.
- Даты используют `acq_date` FIRMS (UTC), без перевода в местный часовой пояс.
- Название архива M-C61 не устраняет различия `version` (6.03 и 61.03).
  Однородность обработки ряда не подтверждена. Причины резкого снижения количества
  строк в 2024–2025 отдельно не установлены.
- Медиана 2007–2024 — база выбранной выгрузки, а не установленная климатическая норма.
  В базе нет поправки на площадь, число пролётов, облачность и полноту покрытия.
- Источник: [NASA FIRMS](https://firms.modaps.eosdis.nasa.gov/),
  [описание полей MODIS](https://firms.modaps.eosdis.nasa.gov/download/Readme.txt).
  Исходный CSV предоставлен пользователем; повторной загрузки NASA и пополнения данных не было.

## Простая загрузка в корень GitHub

1. Распакуйте `Rychfire_v0.2.1.zip` на компьютере.
2. Откройте https://github.com/arychshanova/Rychfire и выберите ветку `main`.
3. Нажмите **Add file → Upload files**.
4. Перетащите **файлы из архива**, а не ZIP и не папку, в окно загрузки.
   `app.py`, `requirements.txt` и `fire_archive_M-C61_833601.csv` должны оказаться
   рядом в корне репозитория. Замените одноимённые старые файлы.
5. Введите описание `Rychfire v0.2 — real MODIS data` и нажмите **Commit changes**.
6. Если приложение уже подключено к Streamlit Community Cloud, откройте его и дождитесь
   перезапуска. Если нужно, выберите **Reboot app**. Путь главного файла — `app.py`.
   При новом развёртывании выберите этот репозиторий, ветку `main`, файл `app.py`, Python 3.11.
7. После запуска убедитесь, что при стандартных фильтрах показано **55 533** обнаружления.

Для локального запуска нужен Python 3.11 или 3.12. Из папки с файлами:

```sh
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows вместо предыдущей строки:
# .venv\Scripts\activate
python -m pip install -r requirements.txt
python verify.py
python -m streamlit run app.py
```

## Что проверено при сборке

Проверены синтаксис, контрольная сумма, число строк, тип сенсора, даты, суммы календарей,
годовые итоги, сохранение исходных полей, выборка карты, пустые фильтры и формула отклонений.
CSV в архиве должен иметь ту же контрольную сумму, что оригинал.

**Ограничение:** библиотеки Streamlit, Plotly и Folium в среде сборки отсутствовали;
их установка была отклонена пользователем. Поэтому полный запуск интерфейса, рендеринг
Folium и взаимодействие в браузере здесь не проверены. Успешная проверка расчётов не
является подтверждением полного запуска приложения. Фиксированные версии зависимостей
также не прошли совместный установочный тест в этой среде.
